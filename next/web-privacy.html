Tsukigashizumu Studio · Website privacy

Website privacy

Updated 29 October 2026 · Website only (not an iOS app privacy policy)

This policy describes how this website currently works. Google Analytics is disabled. Before enabling analytics or materially changing how information is handled, we will review and update this policy and any required consent controls.

1. What this website does

This website presents apps by Tsukigashizumu Studio. Visitors can choose a display language and a country or region of the App Store, inspect publicly available app information, and follow links to Apple's App Store. Choosing a country on this website does not change the country of a visitor's Apple Account or guarantee that an app can be purchased there.

2. Requests to Apple

When a storefront is selected or the catalog is loaded, the website may request public app details and prices directly from Apple's itunes.apple.com Lookup API. These requests contain the selected country code and publicly listed app IDs. Because the visitor's browser makes the request, Apple can receive technical connection information such as an IP address and browser headers according to its own practices. Following an App Store link takes the visitor to apps.apple.com, where Apple's terms and privacy practices apply. A missing lookup result is not proof that an app is unavailable for sale.

3. Information kept in the browser

The website uses local browser storage to remember the selected display language and, when manually chosen, the App Store country or region. In-memory app lookup results may be reused briefly while the page is open. The website does not require an account to browse the app collection.

4. Optional website analytics

Google Analytics 4 (GA4) is currently disabled; no GA4 measurement ID is configured. A separate website consent interface has been prepared for possible future use. If the operator later verifies and enables GA4, analytics scripts are designed not to load until the visitor actively agrees. Declining analytics must not prevent ordinary browsing or App Store links. An analytics choice, if offered, can be stored in the browser and changed from “Analytics choices” on the app collection page.

If enabled after approval, GA4 may process website page visits, certain browser and cookie information, and clicks on App Store links to produce aggregate reporting. These website clicks are not proof of an App Store purchase. The current implementation does not include advertising personalization. Data retention, Google property ownership, and required regional consent arrangements must be checked before GA4 is enabled.

5. Site hosting and app-to-site links

The website uses GitHub Pages hosting. The hosting provider may process routine access data, such as requests and technical logs, according to its practices. App-to-site links are designed to carry only fixed campaign attribution labels; they do not carry an app user's name, email address, device identifier, calculation contents, or other app records. The website's use of Apple's public Lookup API is separate from consent for GA4.

6. Questions and changes

For questions about this website, contact tsukigashizumu@gmail.com. GA4 remains disabled, and no future GA4 data retention period is asserted until it is verified. We will update this policy if the way this website handles information changes materially.

Detailed privacy information is available in English and Japanese. Other website interface languages currently display the English policy.

ウェブサイトのプライバシー

更新日：2026年10月29日 · 本文書はウェブサイトに関する説明であり、iOSアプリのプライバシーポリシーとは別です。

このポリシーは、現在のウェブサイトでの情報の取り扱いを説明しています。Google Analyticsは現在無効です。将来、アクセス解析を有効にする場合や情報の取り扱いを大きく変更する場合には、事前に本ポリシーと必要な同意管理を見直し、更新します。

1. このサイトでできること

Tsukigashizumu Studioのアプリを紹介するウェブサイトです。閲覧者は表示言語とApp Storeの国・地域を選び、公開されているアプリ情報や価格を確認して、AppleのApp Storeへ移動できます。サイトで国・地域を選んでも、Apple Accountの国・地域は変更されません。また、選択したストアで購入できることを保証するものではありません。

2. Appleへの通信

国・地域の選択時やアプリ一覧の読み込み時に、公開アプリ情報と価格を、閲覧者のブラウザからAppleの itunes.apple.com Lookup APIへ直接照会することがあります。照会には選択した国コードと公開アプリIDを使用します。ブラウザから直接通信するため、AppleにはIPアドレスやブラウザの通信ヘッダーなどの技術情報が、Appleの取り扱いに従って伝わる可能性があります。App Storeのリンクを開くと apps.apple.com に移動し、以後はAppleの規約・プライバシー上の取り扱いが適用されます。照会結果が0件であることは、その地域で販売されていないことの確定を意味しません。

3. ブラウザ内に保存する情報

表示言語と、閲覧者が手動で選んだApp Storeの国・地域を、ブラウザのローカルストレージに保存します。ページを開いている間、取得済みの商品情報を短時間再利用する場合があります。アプリ一覧の閲覧にアカウント登録は必要ありません。

4. 任意のアクセス解析

現在、Google Analytics 4（GA4）は無効で、計測IDも設定されていません。将来の利用に備えて、ウェブサイト専用の同意画面を用意しています。運営者が必要事項を確認してGA4を有効化する場合も、閲覧者が明示的に同意する前には解析スクリプトを読み込まない設計です。解析を拒否しても通常の閲覧やApp Storeへの移動は妨げません。同意選択が提供された場合、その選択はブラウザに保存され、アプリ一覧の「解析の設定」から変更できます。

有効化後は、ページ閲覧、Cookieやブラウザに関する一部の情報、App Storeリンクのクリックなどが、Googleによってサイトの利用状況の集計に使われる可能性があります。ウェブ上のクリックはApp Storeでの購入を証明しません。現行の実装では広告のパーソナライズは行いません。GA4を有効化する前に、データ保持期間、GA4プロパティの管理者、各地域で必要な同意手続きを確認します。

5. ホスティングとアプリからのリンク

このサイトはGitHub Pagesをホスティングに利用します。ホスティング事業者が、通常のアクセス記録や技術的なログを取り扱う可能性があります。アプリからのリンクには、定型の流入経路ラベルのみを付与する設計で、利用者の氏名、メールアドレス、端末識別子、計算内容、その他のアプリ記録は含めません。Appleへの公開API照会と、GA4への同意は別のものです。

6. 問い合わせと変更

このウェブサイトに関するお問い合わせは tsukigashizumu@gmail.com までご連絡ください。GA4は現在無効であり、将来のGA4データ保持期間は確認が完了するまで断定しません。ウェブサイトでの情報の取り扱いに重要な変更があれば、本文書を更新します。

詳細なプライバシー情報は日本語と英語で提供しています。ほかの表示言語では、現在は英語版のポリシーを表示します。
