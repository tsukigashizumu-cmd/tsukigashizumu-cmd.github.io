MinPick App Store metadata source

Place the full App Store metadata JSON here:

  en/assets/locales/appstore-metadata.json

Expected shape:

{
  "en-US": {
    "name": "MinPick",
    "subtitle": "Canceled? Know who to contact",
    "promotionalText": "...",
    "description": "...",
    "marketingURL": "https://tsukigashizumu-cmd.github.io/MinPick/en/",
    "privacyPolicyURL": "https://tsukigashizumu-cmd.github.io/MinPick/en/privacy/",
    "supportURL": "https://tsukigashizumu-cmd.github.io/MinPick/en/support/"
  },
  "ja": { ... }
}

The web page reads this file with JavaScript.
Locale selection order:
  1. ?locale=ja or ?lang=ja in the URL
  2. browser language
  3. en-US

Compatibility note:
If metadata contains old URLs like /MinPick/privacy/ or /MinPick/support/,
the page normalizes them to /MinPick/en/privacy/ and /MinPick/en/support/.
